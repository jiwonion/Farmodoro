# Farmodoro MVP 구조

## 핵심 흐름

현실 행동 → Coin 획득 → 씨앗 구매·작물 성장 → 수확 → Morrison 판매 → Farm Money → 농장 꾸미기

Coin은 습관, 할 일, 뽀모도로 완료로만 획득한다.
농장 활동으로 Coin을 다시 생산할 수 없다.

## 화면 구조

### 1. 로그인

- 로그인
- 회원가입
- 비밀번호 찾기

### 2. 홈

- 오늘 날짜와 인사
- 보유 Coin
- 보유 Farm Money
- 오늘의 진행률
- 습관 요약
- 할 일 요약
- 빠른 뽀모도로 시작
- 농장 상태 미리보기

### 3. 생산성

#### 습관

- 습관 목록
- 습관 추가·수정·삭제
- 오늘 완료 처리
- 완료 시 Coin 지급
- 같은 날 중복 보상 방지

#### 할 일

- 오늘 할 일 목록
- 할 일 추가·수정·삭제
- 완료 처리
- 완료 시 Coin 지급
- 완료 취소 시 지급한 Coin 회수

#### 뽀모도로

- 집중 시간 선택
- 사용자 지정 시간
- 시작·일시정지·종료
- 집중 완료 시 시간에 따른 Coin 지급
- 집중 중 농장은 배경으로만 표시

### 4. 농장

- 농장 필드
- 빈 밭 선택
- 씨앗 구매 및 심기
- 작물별 성장 진행도
- Coin 직접 투자
- 수확

MVP 작물:

- 당근
- 토마토
- 옥수수

### 5. 상점

- 씨앗 구매
- 장식 구매
- 보유 재화 표시
- 씨앗은 Coin 사용
- 장식은 Farm Money 사용

### 6. Morrison

- 보유 수확물
- 오늘의 시세
- 작물 판매
- 판매 후 Farm Money 지급
- 특별 주문 영역

### 7. 설정

- 프로필
- 알림
- 집중 시간 기본값
- 배경 선택
- 로그아웃
