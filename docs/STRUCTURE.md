# Farmodoro 구조

## 핵심 흐름

할 일·습관·집중 → Coin 획득 → 2×2 밭과 낚시터에서 Coin 사용 → 작물·물고기 도감과 대표 친구·장식 영구 해금.

현재 화면과 서버 규칙은 [내 작은 농장 v3](farm-v3.md)를 따른다. `095`는 기존 지갑·풍경·정산 기록을 보존하면서 새 농장 상태를 별도로 추가한다. 이전 풍경의 버튼과 화면은 제거했으며 기록은 서버에 보존한다.

## 화면

### 로그인

- Google 계정으로 로그인한다.
- 할 일, 습관, 집중, 지갑과 풍경 기록을 계정에 보관한다.

### 오늘

- 오늘 날짜, 할 일과 습관, 달성률을 함께 보여준다.
- 빠른 집중 타이머와 누적 집중 보상을 확인한다.
- 하단 농장 미리보기와 농장 바로가기는 제공하지 않는다.

### 할 일

- 할 일을 추가·수정·삭제하고 그룹과 날짜로 관리한다.
- 완료하면 Coin을 받고, 완료 취소와 완료 항목 삭제는 지급된 Coin을 함께 정산한다.
- 대기·진행·완료 상태와 보관함을 제공한다.

### 습관

- 반복 요일과 시작·종료일을 정하고 오늘 진행량을 기록한다.
- 습관별 목표 집중 시간과 요일별 목표를 설정할 수 있다.
- 같은 날 중복 보상을 방지하고 월간 달성 기록을 보여준다.

### 집중

- 항목 집중 또는 자유 집중을 시작·일시정지·종료한다.
- 집중과 휴식 시간을 설정하고 누적 집중 시간에 따라 Coin을 받는다.
- 기본 배경, 업로드한 배경 또는 내 농장을 배경으로 선택한다.
- 내 농장 배경은 조작할 수 없는 장식이다. 알림은 집중과 휴식 종료에 사용한다.

### 내 농장

- 2×2 네 칸에 씨앗 비용 없이 무료로 심고 Coin으로 성장시킨다. 물주기·시간 자동 성장·시듦·수확 재화 보상은 없다. 기존 작물·성장도·수확 가능 상태는 보존한다. [농장 조작과 물주기 제거](farm-v3-watering-and-scene-controls.md)를 따른다.
- 낚시터에서는 고른 어종을 Coin으로 완성하고 도감에 수집한다.
- 작물 57종·물고기 24종의 수집으로 대표 친구 16종과 농장 장식을 해금한다. 이후 작물과 어종은 특정 다른 작물의 수확 횟수·어종의 포획 횟수로 해금한다.
- 대표 친구를 선택해 저장하며 낚시 중에는 낚싯대·찌가 있는 모습을 표시한다. 장식은 직접 선택할 때만 배치한다.
- 로그인 사용자는 공개 광장에 자동 참여하며 저장된 대표 친구·위치·말풍선을 불러온다. 순위나 실시간 접속 표시는 없다.
- 이전 풍경 화면은 제공하지 않으며 테마·완성 기록·진행 중 대상과 Farm Money 데이터는 별도 보관한다.

### 사용자 설정

- 프로필 사진과 닉네임, Google 계정 정보, 계정 식별코드를 관리한다.
- 집중 종료 알림, 화면 테마, 로그아웃과 계정 삭제를 제공한다.

## 공통 내비게이션

데스크톱은 왼쪽 사이드바, 모바일은 하단 탭을 사용한다. 주요 화면은 오늘·할 일·습관·집중·내 농장이다. 내 농장 안에는 농장·낚시터·광장·캐릭터·도감 탭이 있다. 모바일에는 내 정보 진입 버튼이 함께 표시된다.

## 현재 데이터와 저장

| 영역 | 주요 데이터 |
| --- | --- |
| 계정 | 프로필, 계정 식별코드, 사용자 설정 |
| 지갑 | Coin, Farm Money, 원장과 보상 요청 기록 |
| 할 일 | 그룹, 날짜, 상태, 완료와 보상 기록 |
| 습관 | 반복 일정, 목표량, 날짜별 진행·집중·보상 기록 |
| 집중 | 진행 세션, 실제 집중 시간, 누적 보상 시간 |
| 농장 v3 | 프로필·대표 친구, 네 칸 작물과 한 낚시 진행, 도감, 영구 해금, 공개 광장 위치·말풍선 |
| 이전 풍경·테마 | 보유 테마, 기존 단일 진행 대상과 완성 이력 |
| 이전 시스템 정산 | 계정별 일회성 환급 결과와 감사 기록 |

재화 차감·성장·보상·해금은 서버 RPC에서 처리한다. 화면은 응답을 확인한 뒤 지갑과 진행도를 반영한다. 응답을 놓친 작업은 계정별로 저장한 같은 요청 ID로 재확인하여 중복 결제를 방지한다. 집중·생산성 보상과 농장 지출은 지갑 작업 순서를 공유한다. 완료 취소는 실제 보상을 회수해 Coin이 음수가 될 수 있으며 도감·작물·장식은 되돌리지 않는다.

## 제거한 시스템

물주기, 기존 시간제 농사·씨앗 재고·시듦, 주방·레시피·음식 판매, 용품·프리패스·랜덤 박스, 밭 스킨·세트 효과, 개인 우편함·친구 선물·운영자 전체 업데이트 우편과 사용자 간 랭킹을 제공하지 않는다. 새 작물·Coin 성장·수확은 v3 별도 테이블을 사용하며 이전 기록의 보관과 정산은 유지한다. `104`는 기존 물주기 기록을 삭제하거나 성장도를 되돌리지 않고 물주기 동작을 중단한다.

## 구현 파일

- `app.js`: 로그인, 생산성 기록, 지갑, 오늘·집중·농장 화면 통합
- `farm-v3.js` / `farm-v3-views.js` / `farm-v3.css`: 농장·낚시·광장·대표 캐릭터·도감과 서버 연동
- `farm-v3-catalog.js` / `farm-v3-art.js` / `farm-v3-crop-art.js`: 카탈로그와 PNG 그림 렌더링
- `farm-v3-character-art.js` / `farm-v3-characters-view.js`: 완성된 슬라임·친구 16종 표시와 선택·진행도. `097_representative_characters.sql`이 해금과 선택을 검증·저장하고, `103_fish_species_paths_and_friends.sql`이 새 어종과 친구를 추가한다. 예전 `farm-v3-avatar.js`는 앱에서 로드하지 않는다.
- `assets/farm-v3/`: 새 배경·슬라임·친구·물고기 그림과 이전 캐릭터 제작 기록
- `scenery-creations.js` / `scenery-creations.css`: 이전 풍경 진행 복구·완성·기록
- `scenery-creation-art.js`: 대상의 단계별 그림
- `scenery-theme-presets.js` / `garden-art.js`: 테마별 종류와 배경 그림
- `scenery-workspace.css`, `farm-workspace.css`, `garden-shell.css`: 내 풍경 화면 배치와 테마 선택
- `garden-modals.css`: 이전 테마 미리보기
- `sw.js`: 현재 화면과 필요한 그림만 오프라인 캐시에 보관
- `supabase/migrations`: 서버 상태, 권한, 재화 원장과 이전 시스템 정산
