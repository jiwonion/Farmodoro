# Farmodoro 구조

## 핵심 흐름

할 일·습관·집중 → Coin 획득. 농장 개편 기간에는 모든 풍경 테마·종류를 무료 제공하며, 버튼으로 대상을 키워 완성하면 Farm Money를 받는다.

현재 보상 화면은 [내 풍경 만들기](scenery-creations.md)를 따른다. `094` 적용 후에는 [풍경 전체 해금과 무료 성장](free-scenery-access.md)을 사용한다. 계정 전체에서 동시에 만드는 대상은 하나다. Coin 차감 없이 성장 버튼으로 진행도와 모습이 변하고, 완성 보상을 받은 뒤 다음 대상을 시작한다. 테마를 바꿔도 진행 중인 대상의 종류·배경·진행도는 유지한다.

## 화면

### 로그인

- Google 계정으로 로그인한다.
- 할 일, 습관, 집중, 지갑과 풍경 기록을 계정에 보관한다.

### 오늘

- 오늘 날짜, 할 일과 습관, 달성률을 함께 보여준다.
- 빠른 집중 타이머와 누적 집중 보상을 확인한다.
- 진행 중인 풍경과 성장률, 보유 재화를 미리 보여준다.

### 할 일

- 할 일을 추가·수정·삭제하고 그룹과 날짜로 관리한다.
- 완료하면 Coin을 받고, 완료 취소와 완료 항목 삭제는 지급된 Coin을 함께 정산한다.
- 대기·진행·완료 상태와 보관함을 제공한다.

### 습관

- 반복 요일과 시작·종료일을 정하고 오늘 진행량을 기록한다.
- 습관별 목표 집중 시간과 요일별 목표를 설정할 수 있다.
- 같은 날 중복 보상을 방지하고 월간 달성 기록을 보여준다.

### 집중

- 항목 집중 또는 자유 집중을 시작·일시정지·종료한다.
- 집중과 휴식 시간을 설정하고 누적 집중 시간에 따라 Coin을 받는다.
- 기본 배경, 업로드한 배경 또는 진행 중인 내 풍경을 배경으로 선택한다.
- 내 풍경 배경은 조작할 수 없는 장식이다. 알림은 집중과 휴식 종료에 사용한다.

### 내 풍경

- 현재 테마에 어울리는 대상을 골라 무료로 시작한다.
- Coin 차감 없이 단계별 모습을 완성하고, 완성 시 Farm Money를 받는다.
- 모든 계정의 대상 종류와 풍경 테마를 전부 영구 해금한다. 새 계정도 동일하게 제공한다.
- 완성한 종류별 횟수와 전체 완성 수를 기록한다.
- 풍경 테마를 미리 보고 무료로 적용한다. 별도 밭 스킨은 제공하지 않는다.
- 주간 Farm Money 획득 순위를 랭킹에서 확인한다.
- 이전 시스템의 대상 잔액과 보유품은 서버의 일회성 정산 결과로 안내한다.

### 사용자 설정

- 프로필 사진과 닉네임, Google 계정 정보, 계정 식별코드를 관리한다.
- 집중 종료 알림, 화면 테마, 로그아웃과 계정 삭제를 제공한다.

## 공통 내비게이션

데스크톱은 왼쪽 사이드바, 모바일은 하단 탭을 사용한다. 주요 화면은 오늘·할 일·습관·집중·내 풍경이다. 모바일에는 내 정보 진입 버튼이 함께 표시된다.

## 현재 데이터와 저장

| 영역 | 주요 데이터 |
| --- | --- |
| 계정 | 프로필, 계정 식별코드, 사용자 설정 |
| 지갑 | Coin, Farm Money, 원장과 보상 요청 기록 |
| 할 일 | 그룹, 날짜, 상태, 완료와 보상 기록 |
| 습관 | 반복 일정, 목표량, 날짜별 진행·집중·보상 기록 |
| 집중 | 진행 세션, 실제 집중 시간, 누적 보상 시간 |
| 풍경 | 대상 카탈로그, 영구 해금, 단일 진행 대상, 완성 이력 |
| 테마 | 보유 풍경 테마와 현재 적용 테마 |
| 랭킹 | 주간 Farm Money 획득 합계 |
| 이전 시스템 정산 | 계정별 일회성 환급 결과와 감사 기록 |

재화 차감·성장·보상·해금은 서버 RPC에서 처리한다. 화면은 응답을 확인한 뒤 지갑과 진행도를 반영한다. 응답을 놓친 작업은 계정별로 저장한 같은 요청 ID로 재확인하여 중복 결제를 방지한다. 집중·생산성 보상과 풍경 지출은 지갑 작업 순서를 공유한다.

## 제거한 시스템

농작물·씨앗·수확·물주기·시듦, 주방·레시피·음식 판매, 용품·프리패스·랜덤 박스, 밭 스킨·세트 효과, 개인 우편함·친구 선물·운영자 전체 업데이트 우편을 제공하지 않는다. 관련 화면과 독립 모듈, 전용 스타일·캐시 참조도 제거한다. 이전 기록의 보관과 정산은 서버 마이그레이션에서 다룬다.

## 구현 파일

- `app.js`: 로그인, 생산성 기록, 지갑, 테마와 랭킹, 화면 통합
- `scenery-creations.js` / `scenery-creations.css`: 단일 대상 만들기·해금·완성 기록
- `scenery-creation-art.js`: 대상의 단계별 그림
- `scenery-theme-presets.js` / `garden-art.js`: 테마별 종류와 배경 그림
- `scenery-workspace.css`, `farm-workspace.css`, `garden-shell.css`: 내 풍경 화면 배치와 테마 선택
- `garden-modals.css`: 테마 미리보기와 주간 랭킹
- `sw.js`: 현재 화면과 필요한 그림만 오프라인 캐시에 보관
- `supabase/migrations`: 서버 상태, 권한, 재화 원장과 이전 시스템 정산
