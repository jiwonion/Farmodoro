# 주방과 스킨 세트 (272)

## 적용

`071_public_recipes_and_cosmetic_sets.sql`, `072_diverse_cosmetic_set_effects.sql` 순서로 적용하고 프런트엔드를 함께 배포한다.
운영 DB에는 자동 적용하지 않았다. 신규 요리·스킨과 세트 효과의 서버 판정에는 이 마이그레이션이 필요하다.
서비스 워커 캐시는 272이며, 신규 테마 SVG 3개도 사전 캐시에 포함한다.

## 주방

- 레시피 43종을 모두 공개한다. 보유 수확물로 제작 가능한 요리를 먼저 표시한다.
- 요리를 누르면 2~3개 재료를 자동 선택한다. 실제 소모는 기존 요리 시작 버튼에서 발생한다.
- 선택 중에는 선택한 재료를 포함하는 제작 가능 요리로 목록을 좁힌다. 재료 비우기로 전체 목록에 돌아간다.
- 레시피에 제작 가능한 최대 개수 또는 부족한 재료를 표시한다. 개수는 해당 요리만 만들 경우의 최대치다.
- 체리 타르트, 고구마 해바라기 샐러드, 뿌리채소 수프, 케일 콩 스튜를 추가해 57종 작물을 모두 활용한다.
- 신규 음식은 기존 타르트·샐러드·수프·스튜의 픽셀 그림을 공유한다.
- 발견 상태·잠금·발견 축하 연출을 제거한다. 기존 DB 발견 테이블은 이전 상태 RPC와의 호환을 위해 보존하며 신규 제작은 읽거나 쓰지 않는다.

## 세트

보유 여부가 아니라 현재 장착한 테마·밭·명패를 센다. 순서와 관계없이 1부위 1%, 2부위 5%, 3부위 10%를 적용한다.
단계별 효과를 합산하지 않으며, 서로 다른 세트는 각각 적용한다. 세트마다 효과가 하나씩 달라 12종 효과가 모두 서로 다르다.
확률 효과는 서버가 판정하며(클라이언트는 결과 표시만 한다) 발동하면 토스트에 보너스가 표시된다.
예: 벚꽃 테마 + 용암 밭 = 시들기 시간 1% 증가와 물주기 쿨타임 1% 감소.
현재 장착 상태를 기준으로 진행 중인 물주기·시들기 잔여 시간도 갱신한다. 이미 시든 작물은 되살리지 않는다.

## 검증

- `node --test tests/sync.test.cjs tests/farm-kitchen-sets.test.cjs`
- `node tests/farm-mobile-ui-smoke.cjs`
- `node tests/habits-ui-smoke.cjs`
