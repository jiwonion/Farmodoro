# 로컬 테스트 계정

`start-farm-test.cmd`를 더블클릭한 뒤 브라우저에서 http://127.0.0.1:4188 을 연다. Google 로그인이나 비밀번호 없이 계정을 고르면 된다.

| 계정 | 주소 | 초기 상태 |
| --- | --- | --- |
| 말랑 테스터 | http://127.0.0.1:4188/?account=1 | Coin 300, 수확 33회, 물고기 12회, 친구 3종 |
| 새싹 테스터 | http://127.0.0.1:4188/?account=2 | Coin 30, 수집 기록 없음, 기본 작물 5종과 기본 친구 |

서로 다른 탭에서 두 계정을 동시에 열 수 있다. 한 계정의 위치·대사를 저장한 뒤 다른 계정의 광장에서 새로고침하면 바뀐 모습을 볼 수 있다. 계정은 탭별로 고정하고 잔액·도감·해금도 각각 관리한다.

상단의 `Coin +100`은 테스트 Coin을 채운다. `이 계정 초기화`는 선택한 계정만 처음 상태로 되돌린다. 새로고침해도 기록은 유지되지만 서버를 종료하거나 재시작하면 모두 초기화된다. 운영 데이터는 변경하지 않는다.

테스트 대상은 농장·낚시터·광장·캐릭터·도감이다. 로컬 서버만 테스트 로그인을 주입하며 운영 HTML에 우회 로그인을 넣지 않는다. 서버는 `127.0.0.1`에만 열리고 Git·SQL 파일 등은 제공하지 않는다.

Node.js와 `@electric-sql/pglite`가 필요하다. 현재 PC에는 설치돼 있다. 다른 PC에서는 프로젝트 루트에서 `npm install --no-save --package-lock=false @electric-sql/pglite`를 먼저 실행하거나 `PGLITE_MODULE`에 설치 경로를 지정한다. 실행 명령은 `node scripts/farm-v3-sandbox.cjs`, 포트는 `FARM_SANDBOX_PORT`로 설정한다.

`tests/farm-v3-sandbox-ui.cjs`가 실제 서버·브라우저로 두 계정 진입, 동시 계정 분리, 작물별 조건, 광장 대사 공유, 모바일, Coin 충전·개별 초기화를 검증한다.
