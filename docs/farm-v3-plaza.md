# 자동 참여 광장 · 작물별 해금 · 대표 친구

2026-10-15. 현재 동작과 배포 기준. 캐릭터 그림은 기존 멍한 점눈 버전을 그대로 사용한다.

최신 물주기 제거·맵 안 조작·낚시 그림·배포 버전은 [농장 조작과 낚시 문서](farm-v3-watering-and-scene-controls.md)를 따른다.

## 이번 변경

- 줄인 밭 크기는 유지하면서 네 칸을 2×2로 가깝게 모았다. 지도 왼쪽 27~73%, 위쪽 36~75% 영역을 사용하고 칸 사이 간격을 좁혔다. 작물은 밭 안쪽에 기존 표시 크기의 약 절반으로 배치하며 농장·오늘 미리보기·집중 배경에 같은 비율을 적용한다. 모바일에서 네 밭 모두 44px 이상의 터치 영역을 유지한다.
- 흙 PNG의 비대칭 투명 여백 때문에 씨앗·작물이 흙보다 왼쪽으로 보이던 정렬을 보정했다. 표시 크기를 유지하며 작물 배치를 밭 너비의 3%만큼 오른쪽으로 옮긴다. 작물 이름·수확 상태·성장 바도 실제 흙 중심인 52.1%를 공통 기준으로 사용한다.
- 수확 기록을 확인할 때 장식을 해금과 동시에 배치하던 동작을 수정했다. 101은 예전에 자동 배치된 장식을 한 번 해제하고, 이후에는 사용자가 직접 선택한 장식만 배치한다. 장식 소유권은 유지하며 재실행해도 이후 수동 배치는 지우지 않는다.
- 로그인 시 농장 상태를 초기화하는 기존 흐름에서 광장에 자동 참여한다. 참여 체크박스와 참여 안내문을 없앴으며 모든 농장 프로필을 광장에서 보여준다. 현재 온라인 여부를 추적하지 않고 저장된 모습을 표시한다.
- 광장 중앙 이동 버튼과 위치 상태 안내, 대표 캐릭터의 설명 문단과 되돌리기 버튼을 제거했다. 위치는 지도에서 고르고 캐릭터는 다른 친구를 눌러 다시 선택한다.
- 작물 57종은 기본 5종에서 시작하는 경로로 해금한다. 예: 당근 3회 → 옥수수, 옥수수 4회 → 양파. 모든 신규 해금은 지정된 다른 작물의 수확 기록을 요구하며 저렴한 작물의 총 수확 횟수로 대체할 수 없다. 기존 해금은 유지한다. [전체 작물 조건표](farm-v3-crop-paths.md).
- 실제로 사용할 수 있는 로컬 테스트 계정 2개와 실행기를 추가했다. [테스트 계정 안내](farm-v3-local-test.md).

## 광장 말풍선

- 내 광장 모습에서 `캐릭터 대사`를 입력하면 내 캐릭터 위에 즉시 미리 보인다. 입력 도중 DOM을 교체하지 않아 한글 조합과 커서가 유지된다.
- `광장 모습 저장`으로 닉네임·위치·대사를 함께 저장한다. 다른 사람은 다음 광장 진입이나 새로고침 때 저장된 대사를 본다. 실시간 채팅이나 대화 기록은 만들지 않는다.
- 한 줄 최대 80자(Unicode 코드 포인트 기준)이며 이모지를 지원한다. 말풍선 안에서는 긴 문장이 자동으로 줄바꿈된다. HTML 형태로 입력해도 일반 글자로만 표시한다.
- 입력을 비우거나 `대사 지우기` 후 저장하면 말풍선이 사라진다. 앞뒤 공백은 저장할 때 제거한다. 모든 로그인 사용자가 자동 참여한다.
- 모바일과 지도 가장자리에서는 말풍선을 지도 안으로 보정한다. 입력 글자 수와 서버 제한을 함께 검사하며 제어 문자를 허용하지 않는다.
- `099_plaza_speech.sql`이 `plaza_message`를 추가한다. 상태 응답은 `plazaSpeechVersion:1`, 내 프로필과 공개 주민 응답은 `speech`를 제공한다. 본인만 기존 RPC로 저장할 수 있다.
- 오래 열린 화면이 대사 필드를 생략해 저장하면 기존 대사를 보존한다. 098 이하 서버에서도 농장과 위치 등 기존 기능을 유지하며 말풍선 입력만 준비 안내로 표시한다.

## 광장 위치

- 광장을 클릭하거나 터치하면 내 위치 초안이 즉시 움직인다. `광장 모습 저장`을 누르면 서버에 저장한다(098 서버의 버튼은 `광장 위치 저장`).
- 맵에 포커스한 상태에서 방향키는 2%, Shift+방향키는 10%씩 이동한다. 중앙 이동 버튼과 Home 단축키는 제거했다.
- 닉네임과 대사를 바꾸면서 위치를 골라도 초안은 함께 유지한다. 페이지에 내 프로필이 없는 경우 내 위치 미리보기를 함께 보여준다.
- 좌표는 맵 너비·높이의 백분율이며 x 5~95, y 15~95 범위로 제한한다. 서버는 타입과 범위를 검사하고 소수 두 자리로 저장한다.
- 다른 주민은 저장된 좌표에 표시한다. 페이지를 넘기거나 화면 크기가 달라져도 새 자리를 자동 배정하지 않는다. 다른 사용자와 같은 자리를 선택할 수 있다.
- 다른 사람이 다음에 광장을 열거나 새로고침할 때 저장한 위치가 보인다. 실시간 위치 방송은 없다.
- 서기·쉬기·낚시 미리보기, 광장 자세·선호 구역 선택, 캐릭터에 붙던 낚싯대를 제거했다. 낚시터의 물고기 수집은 유지한다.
- 예전 자세·구역 데이터와 읽기 응답은 오래 열린 클라이언트의 호환을 위해 남긴다. 예전 폼이 저장돼도 새로운 좌표는 유지하며 현재 화면은 이 필드를 사용하지 않는다.

`farm-v3-plaza-view.js`가 화면을 만들고 `farm-v3.js`가 클릭·키보드·초안·저장을 처리한다. 저장에는 기존 계정 격리·지갑 작업 순서·요청 ID 재확인·프로필 버전 충돌 검사가 적용된다. 다른 사용자 ID를 보내도 해당 사용자의 위치를 변경할 수 없다.

## 농장 진입 수정

이전 클라이언트는 `charactersVersion:1`이 없는 정상적인 095·096 응답까지 업데이트 미적용으로 분류해 농장 전체를 막았다. 현재는 기본 기능과 새 기능을 구분한다.

| 서버 상태 | 사용 가능한 화면 |
| --- | --- |
| 095·096 | 농장·낚시·도감·장식·기존 공개 광장. 캐릭터 선택은 준비 안내 |
| 097 | 대표 캐릭터 선택까지 제공. 자유 위치 이동은 준비 안내 |
| 098 | 강화된 조건·대표 선택·저장된 자유 위치 전체 제공 |
| 099 | 저장된 대사 말풍선까지 제공 |
| 100 | 자동 광장 참여·작물별 해금 경로 제공 |
| 101 | 장식 자동 배치 해제·직접 고른 장식만 배치 |
| 새 농장 API 없음 | 기존 풍경 화면으로 진입 |

없는 캐릭터 소유권을 클라이언트에서 만들어내지 않으며 수집·진행·Coin 검증은 유지한다. 이후 서버가 업데이트되면 다시 불러올 때 해당 기능이 열린다. 연결 실패나 잘못된 데이터는 정상 상태로 취급하지 않는다.

## 반영 파일

운영 DB는 이 작업에서 변경하지 않았다. 이미 100까지 적용된 서버에는 [101 SQL](../supabase/migrations/101_manual_farm_decorations.sql)을 적용한다. 그 이전 버전이면 누락된 마이그레이션을 먼저 적용하거나 094 이후용 [통합 업그레이드 SQL](../supabase/operations/2026-10-15-upgrade-farm-v3.sql)을 사용한다. 095~101을 한 트랜잭션으로 적용하며 Coin·Farm Money·도감·기존 해금·대표·위치·대사를 보존한다. 100에서 이전 참여 해제를 자동 참여로 전환하고, 101에서 이전 장식 배치를 한 번 해제한다. 이후의 수동 배치는 재실행해도 보존한다.

프런트엔드는 예전 서버도 지원하므로 먼저 배포할 수 있다. 자동 참여와 신규 작물 조건은 SQL까지 반영해야 완성된다. 100 이하 서버의 자동 배치 값은 현재 화면에서 숨기고 수동 장식 선택은 준비 안내로 표시한다. CSS `v=10`, 컨트롤러 `v=8`, 카탈로그·메인 뷰 `v=7`, 공용 그림 `v=6`, 캐릭터 그림 `v=2`, 캐릭터 선택 `v=4`, 광장 화면 `v=3`, 서비스 워커 `farmodoro-v381`이다.

생성기는 098 → 099 → 100 → 101 순으로 다음 생성기를 실행한다. `scripts/build-farm-v3-paths-sql.cjs`는 100·작물 조건표를 만들고 `scripts/build-farm-v3-decor-sql.cjs`가 101·최신 통합 SQL을 만든다. 예전 마이그레이션의 원래 동작은 보관한다.
