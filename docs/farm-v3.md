# 내 작은 농장 v3

2026-10-15. 승인한 농장 개편안에 2×2 밭, 낚시터, 대표 캐릭터 선택과 공개 광장을 구현했다. 옷입히기를 중단하고 [슬라임·친구 16종의 영구 해금](farm-v3-characters.md)으로 변경했다. 기존 할 일·습관·집중 보상 체계는 유지한다.

최신 물주기 제거·맵 안 조작·낚시 그림과 배포 버전은 [농장 조작 문서](farm-v3-watering-and-scene-controls.md), 작물 해금·광장 규칙은 [광장 문서](farm-v3-plaza.md)를 따른다.

2026-10-17. 내 농장의 이전 풍경 버튼과 연결 화면을 제거했다. 농장 API가 없을 때도 준비 안내와 다시 불러오기를 표시한다. 기존 풍경·테마·정산 기록과 지갑 데이터는 보존한다.

## 화면과 규칙

| 화면 | 동작 |
| --- | --- |
| 농장 | 처음부터 네 칸을 사용한다. 씨앗 비용 없이 무료로 심고 Coin으로 성장시킨 뒤 수확한다. 물주기는 제공하지 않으며 시간이 지나도 자동으로 자라거나 시들지 않는다. |
| 낚시터 | 목표 어종을 먼저 고른다. 무료로 시작하고 Coin으로 진행해 물고기를 도감에 등록한다. 확률 추첨이나 타이밍 조작은 없다. |
| 캐릭터 | 해금된 슬라임·친구 중 대표를 골라 저장한다. 농장·낚시터·광장에 같은 대표가 표시된다. 장식 해금·선택 영역과 농장·낚시터·집중 배경의 장식 표시는 제거했다. |
| 광장 | 로그인 사용자는 자동 참여한다. 닉네임·대표 캐릭터·저장한 위치·말풍선을 표시한다. 원하는 곳을 눌러 내 위치를 고르고 저장한다. 한 번에 12명이며 조회할 때 저장된 모습을 읽는다. |
| 도감 | 작물·물고기별 수집 횟수와 다음 해금 조건을 표시한다. |

- 작물 57종. 당근·감자(성장 3칸), 딸기·토마토(4칸), 호박(6칸)은 처음부터 사용한다. 이후 작물은 특정 다른 작물을 정해진 횟수만큼 수확하면 해금한다. 이미 해금한 작물은 유지한다.
- [어종 24종](farm-v3-fish-paths.md). 피라미·붕어부터 시작해 특정 물고기를 3~8회 낚으면 다음 어종을 연다. 한 마리 완성 비용은 2~9 Coin이다. 이미 해금한 어종은 유지한다.
- 대표 캐릭터 16종. 새싹 슬라임은 기본이며 수확·물고기 획득·작물과 어종의 수집 종류 기록으로 나머지를 자동 해금한다. 대표 선택과 해금은 Coin을 추가로 쓰지 않는다.
- 첫 수확은 표지판, 물고기 10회 획득은 물방울 슬라임을 해금한다. 작물 3종 수집 시 화단을 열고, 수집량에 따라 장식 6종을 추가한다. 장식은 직접 선택해야 배치된다.
- 수확과 물고기 획득은 Coin이나 Farm Money를 지급하지 않는다. 보상은 도감·영구 해금이다.
- 1 Coin 또는 최대 5 Coin씩 진행한다. 서버는 잔액과 남은 진행도만큼만 차감한다. 잔액이 음수이면 Coin 진행은 잠기지만 완료된 대상 수집은 가능하다. 심기는 계속 무료이며 기존 작물과 성장도·수확 상태는 물주기 제거 후에도 보존한다.
- 완료 취소는 실제 지급된 보상을 회수한다. 할 일과 습관 완료는 1 Coin이며 습관의 최소·최대 단계 변경은 추가 지급이나 차감 없이 기존 지급액을 유지한다. 과거 지급액도 유지하며 취소할 때 실제 지급액을 회수한다. 여러 건을 취소하면 음수 잔액이 누적되고, 이미 수확한 작물·도감·장식은 유지한다.
- 공개 광장은 실시간 접속 표시·순위·실시간 채팅·선물 기능을 제공하지 않는다. 저장한 80자 말풍선은 다른 사람이 화면을 불러올 때 보인다. 공개 닉네임 기본값은 계정 실명 대신 `새싹 농부`다.
- 오늘 하단의 농장 미리보기와 바로가기는 제공하지 않는다. 집중 배경에는 조작 없는 네 칸 농장을 표시한다.
- 맵은 원본의 정사각형 비율을 유지하며 일반 농장·낚시터·광장에서는 원본 한 패널 너비인 724px까지만 표시한다. 집중 배경은 같은 비율로 화면을 채운다.
- 대표 카드를 고르면 초안만 바뀐다. `대표 캐릭터로 선택`을 눌러야 저장된다. 기존 코디 JSON과 옷·모자 보유 기록은 보존하지만 편집·신규 해금은 중단한다.

## 저장과 복구

`095_farm_v3_world.sql`은 새 프로필·진행·도감·해금 테이블을 추가한다. 기존 Coin, Farm Money, 테마 소유권, 풍경 완성·정산 기록은 삭제하거나 변환하지 않는다.

인증 사용자는 자기 데이터만 직접 읽을 수 있으며 테이블 쓰기는 막는다. 변경 RPC가 소유권·해금·Coin·프로필 버전을 검증한다. 광장 RPC는 참여자의 공개 필드만 반환한다. 사용자 간 랭킹 RPC 실행 권한은 회수한다.

농장 요청은 보내기 전에 계정별 요청 ID와 내용을 로컬 저장소에 보관한다. 응답 유실 시 같은 요청으로 확인하고 최신 상태를 다시 읽어 중복 차감·중복 수확을 막는다. 서버에는 요청의 결과 이벤트를 보존한다. 예전 풍경 시작 요청도 이미 성공한 요청이면 복구할 수 있다. 계정 전환 시 이전 계정의 응답을 버리며 생산성 보상과 농장 지출은 지갑 작업 순서를 공유한다.

## 운영 적용

1. 기존 `001`~`094`가 적용된 Supabase에 [통합 업그레이드 SQL](../supabase/operations/2026-10-15-upgrade-farm-v3.sql)로 `095`~`104`를 적용한다. 이미 `103`까지 적용됐다면 [104 물주기 제거 SQL](../supabase/migrations/104_remove_farm_watering.sql)만 추가하면 된다. 사용자 UUID나 이메일 입력은 필요 없다.
2. 새 JS·CSS·`assets/farm-v3/`와 변경된 파일을 함께 배포한다. 현재 캐시는 `farmodoro-v404`이며 내 농장 CSS는 `v22`, 캐릭터 선택 화면은 `v5`, 화면 스크립트는 `v15`, 동작 스크립트는 `v14`다.
3. 새로고침 후 무료 심기, 물주기 버튼·대기 시간 제거, 맵 안 Coin 버튼, 기존 성장도·수확 가능 상태, 낚시 모습, 대표 친구 해금·저장, 자동 공개 광장·말풍선을 확인한다. 이전 풍경 버튼과 화면은 표시하지 않는다.

프런트엔드는 예전 서버에서도 농장·낚시를 열고 아직 없는 기능만 준비 안내를 표시한다. 새 농장 API 자체가 없으면 준비 안내와 다시 불러오기 버튼을 표시한다. 프런트엔드를 먼저 배포할 수 있으며 SQL 반영 후 다시 불러오면 새 기능이 열린다. [광장 위치·강화 조건·호환 규칙](farm-v3-plaza.md)을 따른다.

로컬 구현·격리 DB·브라우저 검증과 운영 DB 적용·배포는 별개다. 이 작업에서는 운영 DB를 변경하지 않았다.
