# 내 정원과 간편 주방

## 사용 흐름

할 일·습관·집중으로 Coin을 얻고 빈 밭을 눌러 작물을 심는다. 보유 씨앗이 있으면 먼저 사용하며, 없으면 Coin 구매와 심기를 하나의 서버 거래로 처리한다. 작물은 Coin 돌보기와 무료 물주기로 키운다. 집중 → Coin 획득 → 작물 돌보기 → 수확으로 이어지며, 집중 대상 밭 선택과 타이머의 직접 성장은 제거했다. 세트 효과는 유지하며, 집중 보상 저장·복구 규칙은 [집중 보상과 작물 돌보기](focus-farm-growth.md)를 따른다.

수확물은 주방의 재료 목록에 모인다. 레시피와 수량을 골라 요리하고 완성한 음식을 모두 판매하여 Farm Money를 얻는다. 작물 직접 판매와 별도 수확물 팝업은 사용하지 않는다. 주방의 43개 레시피와 서버 검증·중복 요청 복구를 유지한다.

테마는 기본 포함 19종을 모두 표시한다. 구매한 테마는 영구 보유하며 언제든 적용할 수 있다. 밭은 기본 흙밭과 구매 가능한 12종을 따로 표시한다. 벚꽃밭·얼음밭·초콜릿밭·사탕밭·별빛밭·낙엽밭·눈밭·모래밭·용암밭·무지개밭·황금밭·라벤더밭은 각각 800 Farm Money다. 일일 추천 목록과 관계없이 미리보기에서 구매하고 적용할 수 있다. 현재 테마와 어울리는 밭에 추천 표시를 붙인다. 기존 밭 ID·보유 이력·가격·세트 효과는 유지한다.

테마와 밭은 독립적으로 적용한다. 테마를 바꿔도 구매한 밭과 재배 중인 작물을 유지한다. 기본 흙밭으로 되돌려도 구매 기록은 남는다. 세트 효과는 장착한 테마와 밭으로만 계산한다. 모든 세트 효과는 같은 세트의 테마나 밭 중 하나만 장착하면 5%, 둘 다 장착하면 10%로 적용하며 `장착한 테마·밭 효과`에서 확인한다. 상점과 미리보기의 세트 설명도 같은 5%/10% 기준을 사용한다. 농장 이름 명패는 사용하지 않는다. 우편함은 상단 버튼으로 열어 편지와 선물을 이용한다.

집중 화면은 3:2 농장 전체를 `max(100cqw, 150cqh)`로 균일 확대해 일반 화면과 전체화면을 모두 채운다. 화면 비율에 따라 가장자리 일부가 잘릴 수 있으며 그림과 9칸 밭은 같은 비율·좌표로 표시된다. 배경은 비활성이며 타이머·버튼은 계속 사용할 수 있다.

## 구현과 배포

- `garden-art.js`, `garden-shell.css`: 19종 배경, 기본 흙밭과 12종 테마 밭, 심어진 작물. 농장·미리보기·집중 배경은 같은 그림을 사용한다.
- `garden-seeds.js`: 빈 밭의 작물 선택과 서버 구매·심기 반영.
- `garden-kitchen.js/css`: 검색·제작 가능 순서·수량·음식 모두 판매·보유 재료.
- `garden-modals.css`: 테마·밭 미리보기, 용품, 랭킹, 우편함, 프리패스 창을 주방처럼 넓은 2단(목록·그림 + 큰 상세 패널)으로 표시한다. 미리보기의 가격·구매 버튼은 하단 고정 바, 용품은 카드를 고르면 상세 패널에서 구매·사용한다. 화이트/다크 앱 UI를 따르며 농장 테마는 지도에만 적용한다.
- `farm-scenery.css`: 집중 배경 확대.
- `075_focus_farm_growth.sql`: 이전 집중 성장과 집중 기록의 기반. 기존 적용 순서를 유지하며 직접 성장은 080에서 종료한다.
- `076_garden_decorations_and_simple_kitchen.sql`: 현재 내용은 공용 거래 잠금, 씨앗 구매·심기, 수량별 요리와 음식 전체 판매, 작물 판매 종료다. 이전에 검토한 마이그레이션 번호·파일명은 유지한다.
- `077_garden_theme_and_decoration_collection.sql`: 현재 내용은 신규 테마 6종, 기존 효과의 대체 테마, 서버 카탈로그 가격 검증이다.
- `079_retire_label_effects_two_piece_sets.sql`: 세트 효과를 테마·밭 2부위(1%/5%)로 바꾸고, 명패를 세트·카탈로그·일일 추천·장착에서 제외한다. 명패 구매·장착 요청을 거부하고 랭킹 결과에서 명패 열을 뺀다. 명패 보유 기록은 구매 이력으로 남긴다.
- `078_retire_farm_decorations.sql`: 이전 설치의 장식 API·테이블·요청 기록을 삭제하고 주방·씨앗의 공용 잠금을 교체한다. 지갑과 테마·밭·명패 보유 기록은 보존한다.
- `080_retire_focus_farm_growth.sql`: 집중 대상 선택과 직접 성장을 종료하고 집중 기록을 Coin 보상만 처리하도록 바꾼다. 기존 `record_my_focus_time_v2` 요청은 대상 밭·작물을 무시하는 호환 API로 받는다. 기존 집중 성장 기록과 이미 자란 작물, 보유 재화·씨앗·수확물은 보존한다.
- `081_harvest_double_probability.sql`: 수확량 2배 세트 효과의 확률을 1부위 5%, 2부위 10%로 높인다. 다른 세트 효과는 1%/5%를 유지한다.
- `082_farm_set_percentages.sql`: 벚꽃을 포함한 모든 세트 효과를 1부위 5%, 2부위 10%로 통일해 상점·미리보기 설명과 서버 판정을 맞춘다.

075 → 076 → 077 → 078 → 079 → 080 → 081 → 082 순서로 적용한다. 기존 079까지 적용된 DB에는 080·081·082를 추가 적용하고 프런트엔드를 함께 배포한다. 080까지 적용된 DB에는 081·082를, 081까지 적용된 DB에는 082를 추가 적용한다. 076·077을 이미 적용한 DB에도 078을 적용할 수 있다. 장식 편집기·이미지·구매·배치·회전·보관 UI와 코드 및 브라우저의 대기 요청은 제거했다. 운영 DB에는 아직 적용하지 않았으며, 운영 관리 연결과 배포 경로 확인이 남아 있다.

## 검증과 그림

단위 테스트 119개 통과. 실제 SQL에서 테마·밭의 가격·소유권·구매·적용·세트 효과와 장식 기능 삭제, 씨앗·43개 요리·전체 판매·중복 요청·롤백을 검증했다. Chrome에서 PC와 모바일의 12종 밭 구매, 실패·잔액 부족·무료 재적용·기본 복원을 확인했다. 집중 배경은 5개 해상도 × 일반·전체화면 10조건에서 여백·정렬·비율·조작 UI를 검증했다. 모든 57종의 전용 수확물·성숙 작물 그림을 연결했고, 성장 6단계의 실제 그림 중심이 기본·눈·낙엽 밭 중앙에 놓이는지 PC·모바일에서 확인했다. 우편함의 57종 씨앗·수확물, 씨앗 선택·주방·랜덤 보상의 새 그림과 우편 보내기·받기도 통과했다.
