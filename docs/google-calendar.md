# Google 캘린더 연동 제거

2026-11-25. 운영자 요청으로 Google 캘린더 연동을 제거했다.

- 달력에는 파머도로의 날짜 있는 할 일과 미래 반복 예정만 표시한다.
- Google 연결·해제·캘린더 선택·일정 조회와 수동 일정 추가 링크를 제거했다.
- Calendar API 모듈과 관련 스타일·사전 캐시·전용 테스트를 제거했다.
- 기본 Google 계정 로그인과 Supabase 인증·기기 간 기록 동기화는 유지한다.
- 개인정보처리방침과 서비스 소개를 현재 기능에 맞춰 수정했다.

Google Cloud의 OAuth 클라이언트나 기본 로그인 설정, 기존 사용자가 부여한 권한은 변경하지 않았다. 앱은 Calendar API 권한을 요청하지 않으며 Google 일정에 접근하지 않는다. 이전 구현은 커밋 dcb36e1에서 확인할 수 있다.

검증: 단위 테스트 245개 통과. 브라우저 모의 인증에서 기본 Google ID 토큰 로그인을 확인했다. 파머도로 할 일이 달력에 표시되고 연결·내보내기 링크와 Calendar API 요청이 없는지 확인했다. 320·390·768·1366px에서 달력 가로 넘침과 JavaScript 오류가 없었다. 실제 Google 계정 로그인은 실행하지 않았다.
