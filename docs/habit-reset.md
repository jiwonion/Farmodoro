# 습관 초기화

습관 초기화는 종료일이 지나지 않은 습관의 시작일을 오늘로 바꾸고 달성·진행·집중 기록을 삭제한다. 종료일이 오늘인 습관은 초기화에 포함하며, 종료일이 없는 습관과 아직 시작하지 않은 습관도 기존처럼 초기화한다. 반복 요일이 오늘이 아닌 습관도 포함한다.

종료일이 오늘보다 이전인 습관은 시작일·종료일과 모든 기록을 보존한다. 초기화 후에도 현재 목록에 다시 나타나지 않으며 과거 기록에서 확인할 수 있다. 날짜는 기존 한국 시간 오전 4시 생산성 날짜 기준을 따른다.

## 적용

기존 105까지 적용된 DB에는 [106 마이그레이션](../supabase/migrations/106_preserve_ended_habits_on_reset.sql)을 적용한 다음 클라이언트를 배포한다. 서버 `reset_my_habits`와 클라이언트가 같은 범위를 초기화해야 하므로 양쪽 변경이 필요하다. 마이그레이션 적용 자체는 습관이나 기록을 변경하지 않는다.

이미 이전 초기화로 삭제된 종료일이나 기록은 이 변경으로 복구되지 않는다. 로컬 구현과 검증은 운영 DB 적용이나 배포를 의미하지 않는다.

## 검증

- `node --test tests/habit-reset.test.cjs`: 실제 초기화 버튼 처리에서 종료 습관 보존, 초기화 대상의 날짜 경계와 실패 처리를 확인한다.
- `node tests/habit-reset-sql.cjs`: PostgreSQL/PGlite에서 종료 습관의 날짜·기록 보존, 초기화 대상의 기록 삭제, 사용자 구분, 인증과 재실행을 확인한다. 필요하면 `PGLITE_MODULE`로 설치 경로를 지정한다.
- `node tests/habits-ui-smoke.cjs`: 습관 입력·달성·집중과 반응형 화면을 확인한다.
