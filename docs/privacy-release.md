2026-11-25. 구현·검증 기록. 공개명·문의 이메일·서버 지역을 제공한 운영자가 같은 날 커밋·푸시를 요청했다. 이는 아래 법정 표기 검토나 Google OAuth 검증의 완료를 의미하지 않는다.

## 준비한 페이지

- `privacy.html`: 로그인·외부 SDK 없이 열리는 개인정보처리방침.
- `about.html`: 앱 기능, 파머도로 할 일 달력과 처리방침을 안내하는 공개 서비스 소개.
- `public-pages.css`: 두 페이지의 공통 반응형 스타일. 외부 폰트·추적 스크립트를 사용하지 않는다.
- `index.html`에 로그인 화면과 설정의 공개 페이지 링크를 추가했다. 서비스워커 v409는 두 공개 문서와 앱 화면을 별도로 캐시한다. 공개 문서의 404·오프라인 응답이 앱 로그인 화면으로 대체되거나 앱 캐시를 덮어쓰지 않는다.

## 코드와 대조한 데이터 처리

- Google 계정 기본 정보와 Supabase 인증·기록 동기화.
- 할 일·습관·집중·게임·이전 정산 기록의 계정별 저장.
- 공개 광장의 닉네임·캐릭터·게임 좌표·말풍선과 공개 URL의 업로드 프로필 이미지.
- 운영자 요청으로 Google 캘린더 연동을 제거했다. 기본 Google 로그인만 유지하고 Calendar API 요청·추가 권한 동의·일정 내보내기 링크는 사용하지 않는다. 공개 페이지도 이에 맞춰 수정했다.
- 로컬 진단 최대 200건, 108 적용 서버의 계정별 진단 최대 500건. 14일 정리는 업로드 시 수행하므로 고정 14일 자동 삭제라고 안내하지 않는다.
- 브라우저 복구 사본과 대기 작업은 로그아웃만으로 모두 지워지지 않는다. Google 계정 권한 철회와 파머도로 기록 삭제는 별개다.
- 개인정보 권리 요청은 실제 문의 이메일로 안내한다. 현재 `deleteAccountButton`은 DOM 선언만 있고 클릭 처리가 연결되어 있지 않아, 처리방침에서 해당 버튼을 작동하는 삭제 경로라고 안내하지 않았다. 서버 삭제 RPC는 별도로 존재한다. 이 문서 작업에서 계정 삭제나 실제 데이터 삭제를 실행하지 않았다.

## 게시 전에 운영자가 검토할 내용

- `jiwon`은 운영자가 지정한 공개명이다. 개인정보 보호법의 책임자 성명 또는 담당 부서명·연락처 요건 충족 여부는 별도 확인해야 한다. 닉네임만으로 모든 법적 요건을 충족한다고 보증하지 않는다.
- 저장 리전과 외부 사업자의 모든 처리 국가는 같은 개념이 아니다. Supabase 계약·백업과 로그 설정, GitHub·Google·브라우저 푸시의 실제 국외 처리·수탁자 정보·기간·적법 근거를 운영 계약과 대조한다. 코드로 확인할 수 없는 국가나 고정 삭제 기간은 임의로 기재하지 않았다.
- 앱 운영자가 실제로 지킬 수 있는 열람·삭제·처리 중지 절차와 문의 대응, 업로드 이미지 삭제·백업 정리 절차를 확인한다. 공개 정책은 서비스 운영 방식과 일치해야 한다.
- 이 페이지 작성과 OAuth 검증 승인은 별개다. 현재 Google Cloud의 브랜딩 저장·운영 공개·실제 계정 연결 검증은 완료했다고 보고하지 않는다.
