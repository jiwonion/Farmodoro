# 내 풍경 만들기

2026-10-06. 승인된 [시안](../output/concepts/theme-creations-2026-10-06/concept-board.png)을 바탕으로 구현했다.

## 사용 흐름

할 일·습관·집중 → Coin 획득 → 테마별 대상 하나 선택 → Coin으로 단계별 완성 → Farm Money 보상 → 새 종류 영구 해금 또는 테마 구매.

계정 전체에서 진행 중인 대상은 하나다. 시작은 무료이고, 기본 종류는 처음부터 고를 수 있다. 처음 만드는 종류를 선택할 때 팜머니로 영구 해금하며 이미 해금한 종류의 다음 회차에는 해금 비용이 들지 않는다. 기본 균형은 완성에 20 Coin, 완성 보상 50 Farm Money, 추가 종류 해금 300 Farm Money다. 완성 보상만 모으면 여섯 번 완성해 새 종류 하나를 해금할 수 있다. 1 Coin 버튼과 최대 5 Coin 일괄 사용 버튼을 제공하고 실제 서버에서는 남은 성장량만큼만 차감한다. 모든 종류의 Coin 대비 보상은 같다.

대상을 시작할 때 종류, 테마, 완성 비용과 보상을 저장한다. 테마를 바꾸거나 이후 카탈로그 가격을 변경해도 진행 중인 회차를 유지한다. 완성 후 보상 받기 버튼을 눌러 팜머니를 받으며 완성한 종류와 횟수가 기록에 남는다. 완성 보상은 주간 팜머니 수익에 포함한다.

기존 테마 18종과 기본 배경에 각각 다른 대표 대상을 연결했다. 대표 대상은 해당 테마를 보유하면 무료로 시작한다. 기존 14종과 해금·성장·완성 기록을 그대로 유지하고 15종을 추가해 총 29종(무료 21종, 유료 8종)이다. 각 테마의 이전 선택지도 유지한다. 바다는 산호가 자연스럽게 놓이는 얕은 바닷물 장면을 추가했다. 제작 정보는 [성장 그림](scenery-creation-art.md), [바다 배경](scenery-ocean-art.md), [테마별 비교 보드](../output/theme-growth-2026-10-06/README.md)에 기록했다.

현재 진행은 사용한 Coin, 퍼센트, 완성까지 필요한 Coin, 4단계 타임라인으로 표시한다. 예를 들어 14/20은 70%, 거의 완성(3/4단계), 남은 비용 6 Coin이다. 그림과 단계 이름은 같은 0%, 25%, 60%, 100% 기준을 사용한다. 오늘 화면의 작은 미리보기도 실제 수치와 현재 그림을 보여준다. 선택 카드의 진행 중인 대상은 현재 성장 모습이고, 다른 카드와 테마 목록 그림은 완성 예시로 구분한다.

테마 미리보기는 같은 테마의 진행 중인 대상이 있으면 현재 모습으로 시작하고 실제 진행 수치를 표시한다. 시작·성장 중·거의 완성·완성 예시를 선택하거나 내 현재 모습으로 돌아갈 수 있다. 예시 단계 선택은 코인·성장·테마 선택을 변경하지 않는다. 다른 테마를 구경해도 기존 대상의 종류와 시작한 테마를 유지한다. 열린 미리보기의 실제 수치는 서버 갱신에 따라 다시 표시하며 계정·세션 변경 시 닫는다.

## 클라이언트와 저장

- `scenery-creations.js/css`: 단일 대상, 성장, 보상, 영구 해금, 완성 기록, PC·모바일·다크 테마.
- `scenery-theme-presets.js`: 19개 대표 대상, 단계 설명, 기존 선택지를 포함한 테마별 매핑.
- `scenery-creation-art.js`, `assets/scenery-creations/`: 단계별 투명 그림과 바다 배경.
- `scenery-workspace.css`: 기존 작업 화면, 오늘 미리보기, 집중 배경, 테마 미리보기 연결.
- `app.js`: 인증·지갑·실시간 갱신·테마 구매 및 새 화면 연결. 집중 배경은 현재 풍경을 비활성 그림으로 표시하며 중복 ID와 조작 버튼을 넣지 않는다.
- `086_theme_creations.sql`: 서버 카탈로그, 계정별 영구 해금, 진행·완성 이력과 RPC.
- `087_scenery_unlock_prices.sql`: 초기 100 Farm Money 카탈로그를 사용한 DB의 유료 해금 가격을 300으로 올린다. 보유한 종류와 지갑은 그대로 유지한다.
- `088_theme_specific_creations.sql`: 무료 대표 대상 15종을 추가하고 테마별 첫 선택을 구분한다. 이전 종류의 가격, 지갑, 소유권, 진행 중 대상과 완료 이력을 바꾸지 않는다.
- `089_retire_legacy_farm_and_mail.sql`: 이전 재산을 한 번 정산하고 우편·생산·용품·밭 스킨 접근을 종료한다. 원자료와 환급 근거는 비공개로 보관한다.

서버가 코인 차감과 팜머니 지급을 거래로 처리한다. 브라우저는 작업 전에 계정별 요청 ID를 저장하고 결과를 못 받은 경우 같은 요청을 재전송한다. 해당 요청 기록은 오래 지나도 유지하여 재시작·재접속·다른 기기의 진행 이후에도 코인과 보상을 중복 처리하지 않는다. 재시도 응답은 최신 진행·지갑을 돌려준다. 현재 계정과 세션이 바뀌면 이전 응답을 적용하지 않는다. 풍경·할 일·습관·집중·테마 거래는 공유 지갑 작업 순서를 따른다.

2026-10-07에 우편함·운영자 전체 업데이트 우편·주방·농작물·용품·밭 스킨을 클라이언트에서 제거했다. 관련 숨김 DOM과 실행 코드, 독립 모듈·스타일·캐시 연결도 제거했다. 배경 테마, 단일 풍경 성장, 지갑, 할 일·습관·집중, 주간 랭킹은 유지한다. 기존 자산은 089에서 한 번 정산하며 내 풍경 화면에서 지급 내역을 확인한다. 서버에 남은 이전 시스템은 실행·조회 권한과 realtime을 종료하고 원본 기록을 비공개로 보관한다. 자동 승인 검토가 비가역적 DB 삭제를 거절했으므로 물리 테이블·구매 기록을 삭제하지 않는다. 자세한 기준과 운영 순서는 [농장 개편 정산](scenery-transition.md)을 따른다.

## 운영 적용

085까지 적용한 DB에 086, 087, 088, 089를 순서대로 적용하고 새 클라이언트를 함께 배포한다. 088까지 적용된 DB에는 089를 추가 적용한다. 서비스 워커 캐시는 `farmodoro-v345`이며 종료한 기능의 파일과 그림을 사전 캐시에서 제외한다. `send-push` Edge Function도 새 종료 응답(410)으로 배포하거나 호스팅에서 삭제한다. `dispatch-scheduled-push`를 타이머 종료 알림만 조회하는 최신 코드로 함께 배포해 집중 타이머의 예약 푸시를 유지한다. 088 미적용 환경에서는 새 대표 대상 시작을 준비 중으로 표시하고, 기존 진행 중인 대상은 계속 키울 수 있다.

현재 작업은 로컬 구현과 격리 DB·브라우저 검증까지다. 운영 DB 마이그레이션 적용과 원격 호스팅 배포는 이 작업에서 수행하지 않았다.
