# 우주·고양이 동산 풍경 그림

내장 `image_gen` 도구로 만든 프로젝트 자산. 원본 픽셀과 투명도를 유지해 복사했으며, 우주 나무는 새싹 → 어린 나무 → 성장 → 완성, 턱시도 고양이는 새끼 → 아기 → 청소년 → 성묘의 네 단계를 사용한다.

- `assets/scenery-creations/space-scene-v1.png`: 우주 배경.
- `assets/scenery-creations/cat-park-scene-v1.png`: 턱시도·치즈·페르시안·삼색·샴 고양이 여덟 마리가 쉬는 고양이 동산 배경. 나무 가지 네 곳에도 고양이를 배치했다.
- `assets/scenery-creations/space-tree-v1.png`: 우주 나무 4단계, 투명 PNG.
- `assets/scenery-creations/tuxedo-cat-v1.png`: 실제 턱시도 고양이 성장 4단계, 투명 PNG.

배경은 1536×1024, 성장 시트는 실제 출력 1254×1254다. 대상마다 실제 그림 경계를 측정하고 같은 배율·바닥 기준으로 표시한다. 고양이 동산 배경은 기존 배경을 편집했고, 성장 그림은 기존 그림을 스타일 참조로 사용했다.
