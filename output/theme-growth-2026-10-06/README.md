# Farmodoro · 모든 테마의 성장 디자인 시안

2026-10-06. 사용자의 “성장 모습을 테마별로 전부 보여줘봐” 요청에 대한 **디자인 제안 기록**이다. 이후 “미리보기도 바꿔야지” 요청에 따라 같은 그림을 앱의 로컬 구현에 연결했다. 현재 연결 구조는 [내 풍경 문서](../../docs/scenery-creations.md)에 기록했다. 운영 배포는 별도다.

기본 정원과 기존 테마 18개를 모두 포함한다. 테마별 대표 대상 하나를 시작 → 성장 중 → 거의 완성 → 완성의 4단계로 보여준다. 성장 값은 기존 구조의 0, 5, 12, 20 / 20이다. 성장 비용 20 Coin, 완성 보상 50 Farm Money, 추가 종류 영구 해금 300 Farm Money라는 현재 균형은 유지한다.

## 보기

- [전체 비교 갤러리](index.html): 19개 테마, 76개 성장 그림. 그룹 필터와 성장 단계 강조를 지원하며 외부 서비스 없이 열린다.
- [정원과 꽃](nature-growth-board.png): 초록 정원, 벚꽃, 황금 들판, 봄날 들판, 라벤더 정원.
- [기념일](events-growth-board.png): 발렌타인, 할로윈, 크리스마스, 화이트데이, 빼빼로데이.
- [물과 계절](weather-growth-board.png): 바다, 거품 밭, 비 오는 정원, 얼음 왕국, 사막 오아시스.
- [밤과 판타지](fantasy-growth-board.png): 용암, 은하수 밤, 오로라, 달빛 정원.

원래의 문제를 해결하기 위해 벚꽃은 실제 꽃봉오리와 꽃이 있는 가지 구조, 황금 들판은 나무와 다른 이삭 형태를 사용한다. 서로 비슷한 기념일·수정 테마도 각각 덩굴/꽃다발/과자 건축물과 용암 기둥/오로라 리본 구조로 구분한다.

## 생성 도구와 프롬프트

모든 새 그림은 **내장 `image_gen.imagegen`**으로 생성했다. CLI/API 대체 경로를 사용하지 않았다. 기존 [승인 시안](../concepts/theme-creations-2026-10-06/concept-board.png)은 화풍 참고로만 사용했다. 각 아틀라스의 정확한 프롬프트, 생성 원본 경로, 실제 크기, 검수 내용은 다음 파일에 기록했다.

- [자연 테마 프롬프트](nature-prompt.md)
- [기념일 테마 프롬프트](events-prompt.md)
- [물·계절 테마 프롬프트](weather-prompt.md)
- [판타지 테마 프롬프트](fantasy-prompt.md)

이미지 생성 결과의 실제 행 간격은 균일하지 않아, 테마·단계별로 측정한 `*-bounds.json`을 사용한다. 갤러리는 이 데이터를 내부에 포함하고, 테마별 동일 배율과 바닥 위치로 그림을 자른다. 초기 단계를 완성 단계와 같은 크기로 확대하지 않는다. 그림을 코드로 다시 그리거나 이미지 편집으로 재가공하지 않았다. 비교 보드는 실제 Chrome에서 한국어 설명과 새 그림을 함께 렌더링한 캡처다.

`render-gallery.cjs`는 19개 고유 테마, 76개 그림, 모든 아틀라스 로드, 그룹 필터와 단계 강조를 확인하고 네 비교 보드를 저장하는 로컬 검수 스크립트다.
