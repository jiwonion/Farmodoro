개인정보처리방침

할 일과 집중 기록을 이어 쓰는 데 필요한 정보가 어떻게 처리되는지 안내합니다.

시행일 및 최종 수정일: 2026년 11월 25일 · 운영자: jiwon

Google 계정의 기본 정보를 로그인에 사용합니다. Google 일정·메일·파일 접근 권한을 요청하지 않습니다. 앱 달력에는 파머도로에 등록한 할 일과 반복 예정을 표시합니다.

개인정보는 로그인과 기록 저장·동기화 등 서비스 제공에 사용하며 광고·판매·AI 모델 학습에 사용하지 않습니다.

1. 처리 목적과 개인정보 항목

파머도로는 이용자가 제공한 정보와 동의한 Google 계정 정보를 이용해 로그인, 기기 간 저장·동기화, 생산성 기록과 농장 기능을 제공합니다. Google 비밀번호를 직접 수집하지 않습니다.

로그인과 계정
Google 계정 식별 정보, 이메일, 이름·프로필 이미지 등 동의한 기본 프로필, 파머도로 계정 ID와 로그인 세션을 처리합니다.계정 식별과 로그인 유지, 문의 처리에 사용합니다.
직접 입력한 기록
할 일·그룹·날짜·반복 규칙·완료 상태, 습관과 날짜별 기록, 집중 시간·타이머 설정, 프로필과 앱 설정을 처리합니다.기록 관리, 기기 간 동기화와 집중 보상에 사용합니다.
농장과 광장
농장 코드, Coin과 거래·보상 기록, 작물·낚시·도감·해금·캐릭터, 광장 닉네임·캐릭터·위치·말풍선, 이전 농장과 정산 기록을 처리합니다.게임 진행 저장과 공개 광장 표시에 사용합니다. 광장 위치는 게임 화면의 좌표이며 실제 GPS 위치가 아닙니다.
선택한 부가 기능
프로필 이미지 업로드와 브라우저 알림 구독을 해당 기능을 이용할 때 처리합니다.알림을 허용하지 않아도 기본 할 일·습관·집중 기능을 사용할 수 있습니다.
오류 진단
계정 ID, 무작위 기기 식별값, 이벤트 종류·시각, 앱 버전, 오류 코드, 연결 상태, 처리 시간과 건수·재시도 횟수를 처리합니다.저장 실패·복구와 동기화 문제 확인에 사용합니다. 앱 진단 로그에 할 일 본문·이메일·비밀번호·접근 토큰·오류 원문을 기록하지 않습니다.

2. Google 계정 로그인 정보의 사용

Google 계정으로 로그인할 때 동의한 계정 식별 정보, 이메일, 이름과 프로필 이미지를 인증과 계정 관리에 사용합니다. Google 일정·메일·파일 접근 권한은 요청하지 않습니다.

파머도로의 Google 계정 정보 사용에는 Google API 서비스 사용자 데이터 정책이 적용됩니다. 해당 정보를 판매하거나 광고, 신용 평가 또는 범용 AI 모델 학습에 이용하지 않습니다.

Google에 부여한 계정 접근 권한은 Google 계정의 서드 파티 연결 관리에서 철회할 수 있습니다. 이후 로그인할 때 다시 동의가 필요할 수 있습니다. Google 권한 철회와 파머도로에 저장된 계정·기록의 삭제는 별개이며, 기록 삭제는 아래 문의처로 요청할 수 있습니다.

3. 다른 이용자에게 보이는 정보와 공유

로그인한 이용자는 농장 공개 광장에 참여하며 광장 닉네임, 선택한 캐릭터, 게임 내 위치와 저장한 말풍선이 다른 로그인 이용자에게 보입니다. 말풍선을 비우고 저장하면 해당 내용이 표시되지 않습니다. 공개 영역에 연락처나 민감한 내용을 입력하지 않도록 주의해 주세요.

업로드한 프로필 이미지는 Supabase의 공개 이미지 URL로 제공됩니다. 이미지 주소를 아는 사람은 해당 파일에 접근할 수 있습니다.

할 일·습관 본문은 공개 광장에 표시하지 않습니다. 이용자가 기록을 이미지로 저장하거나 외부 앱에 공유하면 선택한 내용은 이용자가 지정한 수신자나 서비스에 전달됩니다. 외부 서비스에서의 이후 이용에는 해당 서비스의 정책이 적용됩니다.

파머도로는 개인정보를 판매하지 않으며 맞춤 광고를 위해 제공하지 않습니다. 서비스 제공을 위한 아래 외부 처리, 이용자가 직접 선택한 공유 또는 법령에 따른 적법한 요청이 있는 경우를 제외하고 제3자에게 제공하지 않습니다.

4. 보관 기간과 파기

계정과 서비스 기록
서비스 이용 중 기록 유지와 동기화에 사용하며, 이용자의 개별 삭제 또는 계정·데이터 삭제 요청에 따라 파기합니다. 이전 농장·정산 기록도 계정에 연결된 보관 기록에 포함됩니다.
앱 진단 기록
기기에는 계정별 최근 200건, 서버 진단 기능이 적용된 경우 서버에는 계정별 최근 최대 500건을 유지합니다. 새 진단 업로드 때 14일 이전 기록을 정리하므로 업로드가 없으면 다음 업로드 또는 계정 삭제까지 남을 수 있습니다.
기기 저장 데이터
기록 복구 사본, 전송 대기 작업, 로그인 상태·설정과 앱 캐시는 브라우저 사이트 데이터를 지울 때까지 남을 수 있습니다. 로그아웃만으로 모든 로컬 복구 사본이 삭제되지는 않습니다.

삭제 요청을 처리할 때 본인 확인 후 해당 계정의 기록과 업로드 파일을 확인해 삭제합니다. 전자 기록은 복구가 어렵도록 삭제하며, 플랫폼 백업·접속·보안 로그의 정리 시점은 해당 서비스의 계약과 보존 주기에 따릅니다. 법령에 따른 별도 보존 의무가 실제 적용되는 경우에는 해당 항목과 근거·기간을 안내하고 목적을 제한해 보관합니다.

5. 외부 서비스와 보관 위치

Supabase
Supabase Pte. Ltd.의 인증·데이터베이스·이미지 저장·실시간 동기화와 알림 처리 기능을 이용합니다. 운영자가 확인한 프로젝트 저장 리전은 대한민국 서울(ap-northeast-2)입니다.로그인과 계정, 직접 저장한 기록·이미지·설정, 알림 구독과 진단 메타데이터가 처리됩니다. Supabase 개인정보 안내 · 데이터 처리 계약
GitHub Pages
GitHub, Inc.의 정적 웹 호스팅으로 페이지와 앱 파일을 제공합니다. 접속 시 IP 주소·브라우저·요청 정보가 서비스 제공과 보안을 위해 GitHub의 글로벌 인프라에서 처리될 수 있습니다.파머도로의 비공개 할 일·습관 데이터가 공개 소스 저장소에 업로드되는 방식이 아닙니다. GitHub 개인정보 안내
Google
Google 계정 인증을 이용합니다. 인증과 권한 동의, 계정 식별 정보는 Google의 서비스 인프라에서 처리됩니다.Google이 제공하는 서비스의 처리 위치·로그 보존과 권한 관리에는 Google 개인정보처리방침이 적용됩니다.
브라우저 푸시 서비스
알림을 허용하면 브라우저가 지정한 푸시 사업자를 통해 알림 메시지를 전달합니다. 구독 주소·암호화 키와 알림 전달 정보가 처리됩니다.브라우저 설정에서 알림 권한을 철회할 수 있으며, 푸시 사업자는 사용하는 브라우저에 따라 달라집니다.

서울 프로젝트의 저장 리전은 외부 사업자의 모든 지원·접속 로그·글로벌 서비스 처리 위치가 국내라는 의미는 아닙니다. 외부 처리와 국외 처리에 관한 상세 정보·열람·삭제 또는 처리 중지를 원하면 아래 문의처로 요청할 수 있습니다. 필수 인증·저장 처리를 중지하면 로그인과 기기 간 동기화 등 일부 서비스 이용이 제한될 수 있습니다. 선택한 브라우저 알림은 알림 권한만 해제할 수 있습니다.

6. 기기 저장소와 알림

로그인 유지, 화면 설정, 저장 중 종료되어도 기록을 복구하는 기능에 브라우저의 로컬·세션 저장소를 이용하고, 설치형 웹 앱의 화면과 그림을 빠르게 불러오기 위해 서비스워커 캐시를 이용합니다.

현재 앱 코드에는 광고 목적의 추적 도구나 맞춤 광고 쿠키를 설치하지 않습니다. 브라우저에서 사이트 데이터·캐시를 삭제할 수 있으나 로그인 유지와 아직 서버에 저장하지 못한 복구 기록도 함께 지워질 수 있습니다. 알림은 이용자가 허용한 경우에만 사용하며 브라우저의 사이트 권한에서 끌 수 있습니다.

7. 이용자의 권리와 요청 방법

본인의 개인정보 열람, 정정, 삭제, 계정 탈퇴, 처리 정지와 동의 철회를 아래 문의 이메일로 요청할 수 있습니다. 요청자의 계정 소유 여부를 확인한 후 관련 법령에 따라 처리하고 결과를 안내합니다. 본인 확인을 위해 비밀번호나 Google 접근 토큰을 요청하지 않습니다.

프로필과 직접 입력한 기록은 앱에서 수정할 수 있습니다. 로그인·저장에 필요한 정보의 처리를 중지하거나 계정을 삭제하면 그에 해당하는 서비스 이용이 제한됩니다.

8. 정보 보호 조치

HTTPS 통신과 계정별 인증·접근 제어를 사용하고, 저장·조회 요청의 계정 소유권을 확인합니다. 진단 항목은 필요한 메타데이터로 제한합니다. 서비스 운영자는 문의 대응과 장애·보안 문제 처리에 필요한 범위에서만 정보에 접근합니다.

보안 조치는 위험을 줄이기 위한 것이며 이용자의 공용 기기·브라우저 확장 프로그램과 외부 서비스까지 통제하는 것은 아닙니다.

10. 방침 변경

처리 목적·항목·공유·보관 방식이 바뀌면 이 페이지의 내용과 수정일을 갱신하고 중요한 변경 사항을 앱에서 안내합니다. 새로운 Google 데이터 접근이나 이용 목적에 별도 동의가 필요하면 해당 데이터를 사용하기 전에 다시 동의를 받습니다.
